# My Homework Lab — MIT App Inventor ม.3

เว็บบทเรียนออนไลน์ (Static Website) ภาษาไทย สำหรับให้นักเรียนเรียนและสร้างแอปบันทึกการบ้าน `MyHomework_M3` ด้วย MIT App Inventor แบบทำตามทีละขั้น

## ความสามารถ

- 7 โมดูล: ใบความรู้, Designer, Blocks 6 ชุด, แผน 4 คาบ, ใบงาน/แบบทดสอบ, ทดสอบ/ประเมิน, สะท้อนผล/ส่งงาน
- เนื้อหาครบสำหรับแอปพื้นฐาน: เพิ่มรายการ แสดงรายการ เลือกลบ ตรวจช่องกรอก และจัดเก็บถาวรด้วย TinyDB
- เช็กลิสต์ 9 ภารกิจ, แบบทดสอบ 5 ข้อมีเฉลย, Test Cases 6 กรณี, Rubric 20 คะแนน
- เก็บความก้าวหน้าและคำตอบใน `localStorage` ของเบราว์เซอร์โดยอัตโนมัติ
- ดาวน์โหลดผลการเรียนเป็น `.json` และพิมพ์ใบงานได้
- รองรับจอคอมพิวเตอร์และมือถือโดยไม่ต้องใช้ฐานข้อมูลหรือโฮสติ้งแบบเสียเงิน

## ใช้งานในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ หรือใช้เซิร์ฟเวอร์ในเครื่อง เช่น `python -m http.server 8000` แล้วเปิด `http://localhost:8000`

## เผยแพร่บน GitHub Pages

1. สร้าง Repository ใหม่บน GitHub เช่น `my-homework-m3`
2. อัปโหลดไฟล์ `index.html`, `style.css`, `app.js`, `README.md` ไปที่ root ของ default branch
3. ไปที่ **Settings → Pages → Build and deployment** เลือก **Deploy from a branch**
4. เลือก `main` และ `/ (root)` แล้วกด Save
5. เมื่อ GitHub Pages เผยแพร่สำเร็จ จะเปิดได้จาก URL ที่ GitHub แสดงในเมนู Pages (สำหรับ repository ตามตัวอย่างมักเป็น `https://<USERNAME>.github.io/my-homework-m3/`)

> หมายเหตุ: ต้องมี Repository และเปิด GitHub Pages ก่อน จึงจะมีลิงก์ใช้งานจริง

## วิธีใช้ในชั้นเรียน

1. ครูส่ง URL เว็บไซต์ให้นักเรียน
2. นักเรียนกรอกชื่อ ห้อง เลขที่ และเรียนตาม STEP 1–7
3. เปิด MIT App Inventor อีกแท็บเพื่อทำงานจริง แล้วทำเครื่องหมายภารกิจเมื่อทำเสร็จ
4. ทดสอบแอป Android จริง และกรอกผลการทดสอบ
5. ดาวน์โหลดผล `.json`, ส่งไฟล์โครงการ `.aia` และภาพหน้าจอตามช่องทางที่ครูกำหนด

## ข้อจำกัดสำคัญ

- ไม่ใช่ LMS แบบมีบัญชีผู้ใช้ ไม่มีระบบล็อกอิน ส่งงานอัตโนมัติ หรือฐานข้อมูลฝั่งเซิร์ฟเวอร์
- ข้อมูลผู้เรียน/คำตอบเก็บ **เฉพาะในเบราว์เซอร์ของอุปกรณ์นั้น** และอาจหายเมื่อเคลียร์ข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ควรดาวน์โหลดไฟล์ผลการเรียนสำรอง
- รูปแบบ Blocks ในเว็บเป็น **SVG บล็อกต่อกัน 6 ชุด** ที่วาดใหม่สำหรับการสอน พร้อมขั้นตอนภาษาไทยทุกชิ้น ระยะและสีอาจต่างจากตัวแก้ไขจริง นักเรียนต้องลากบล็อกใน MIT App Inventor
- Rubric ที่กรอกบนเว็บยังไม่ใช่คะแนนที่ครูยืนยัน
- เนื้อหาทำแอปที่เก็บรายการเป็นข้อความ 1 รายการต่อ 1 การบ้าน; ไม่ใช่ระบบแก้ไข/เรียงวัน/แจ้งเตือนอัตโนมัติ
- GitHub Pages แบบสาธารณะไม่ควรใช้รับหรือเผยแพร่ไฟล์ JSON ของนักเรียนที่มีชื่อจริง ควรส่งด้วยระบบที่จำกัดสิทธิ์การเข้าถึง เช่น LMS ของโรงเรียน

## โครงสร้าง

- `index.html` — โครงหน้าเว็บ
- `style.css` — รูปแบบ responsive
- `app.js` — เนื้อหา 7 โมดูล, ความก้าวหน้า, แบบทดสอบ, ส่งออกผล
- `README.md` — คู่มือติดตั้งและใช้งาน

ไม่ใช้ไลบรารีภายนอก ไม่มี API key และไม่มีคำสั่งเชื่อมต่อเซิร์ฟเวอร์

## แก้ไขภาพและคำแนะนำ Blocks

แก้ต้นฉบับที่ `scripts/block-guides.cjs` แล้วรัน `node scripts/build-blocks.cjs` เพื่อสร้าง `block-guides.js` และ `assets/blocks/1.svg` ถึง `6.svg` ใหม่ ใช้ Node.js เฉพาะตอนพัฒนา; ผู้เรียนเปิดเว็บได้โดยไม่ติดตั้งไลบรารี

อ้างอิงหลัก: [MIT Built-in Blocks](https://ai2a.appinventor.mit.edu/reference/blocks/) รวม Variables, Lists, Procedures, Control, Logic, Math และ Text; บล็อก Components เทียบกับ [TinyDB](https://ai2a.appinventor.mit.edu/reference/components/storage.html#TinyDB) และ [User Interface](https://ai2a.appinventor.mit.edu/reference/components/userinterface.html#ListView) ตรวจเมื่อ 6 พฤศจิกายน 2569 ภาพเป็นงานวาดใหม่ ไม่ใช้ภาพจากเอกสาร MIT

การทดสอบใน Android ต้องตรวจครบ: เริ่มจากรายการว่าง, ช่องว่าง/เว้นวรรค, เพิ่ม 3 รายการ, เลือกลบรายการกลาง, ลบซ้ำโดยไม่เลือก, ปิดเปิดใหม่แล้วข้อมูลยังอยู่ ใน AI Companion อาจใช้ TinyDB ร่วมกันระหว่างโปรเจกต์ ควรแยก Namespace และทดสอบแอปที่ติดตั้งจริง

## ตรวจสอบการทำงาน

รัน `node --check app.js` และ `node scripts/build-blocks.cjs` จากนั้นเปิด `tests/browser.html` ในเบราว์เซอร์ด้วยโปรไฟล์ทดสอบ (หน้านี้เขียนข้อมูล QA ใน localStorage ของ origin นั้น) หน้าแสดง PASS/FAIL สำหรับเมนู 7 โมดูล ภาพครบ 6 ชุด ไม่มี pseudocode ความกว้างหน้า การบันทึกความก้าวหน้า/ใบงาน/ผลทดสอบ การตรวจ quiz และคืนสถานะหลัง reload

ผลตรวจในงานปรับปรุงนี้: Chrome desktop 1440×1100 และ mobile viewport 390×844 ผ่านการตรวจการทำงาน ตรวจภาพ SVG ทั้ง 6 ชุดด้วยสายตาแล้ว การตรวจนี้ไม่ได้รันโปรเจกต์ App Inventor หรือ Android จริง และตรวจการมีอยู่ของปุ่มส่งออก/พิมพ์ ไม่ได้ยืนยันไฟล์ดาวน์โหลดหรือเครื่องพิมพ์
